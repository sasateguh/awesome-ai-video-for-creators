## Cara pangkat dikira

Setiap entri ialah repositori GitHub awam. Setiap minggu satu skrip membaca bintang, tolakan terakhir dan lesennya daripada API GitHub, kemudian menyusun setiap kategori mengikut

`skor = 1 × log10(1 + bintang) + 1 × max(0, 1 − hari sejak tolakan terakhir ÷ 365)`

Repositori tidak disenaraikan bila ia diarkib, fork, tiada penerangan, kurang daripada 20 bintang atau tiada tolakan selama 365 hari. Bilangan bintang dibundarkan ke bawah kepada gandaan 10 terdekat. Penerangan ialah penerangan GitHub repositori itu sendiri.
