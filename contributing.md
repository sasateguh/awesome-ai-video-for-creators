# Contributing

This list is generated by a script from public GitHub data and refreshed every week. To suggest a repository, open an issue with its link.

A suggestion is added when the repository fits a category of this list, has a description, has at least 20 stars and has been pushed in the last 365 days. The ranking is never changed by hand, and descriptions are the repositories' own GitHub descriptions.

## Bahasa Melayu

Senarai ini dijana oleh skrip daripada data awam GitHub dan dikemas setiap minggu. Untuk mencadangkan repositori, buka isu dengan pautannya.

Cadangan ditambah bila repositori itu sesuai dengan kategori senarai ini, ada penerangan, sekurang-kurangnya 20 bintang dan ada tolakan dalam 365 hari terakhir. Pangkat tidak pernah diubah dengan tangan, dan penerangan ialah penerangan GitHub repositori itu sendiri.
